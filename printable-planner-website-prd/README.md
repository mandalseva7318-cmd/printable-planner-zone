# 📋 Free Printable Planner Hub

A modern, Pinterest-style website for browsing and downloading free printable planners. Built with React, TypeScript, Tailwind CSS, and Vite.

## ✨ Features

### Core Functionality
- **20+ Printable Planners** across 7 categories
- **Search System** - Find planners quickly
- **Category Browsing** - Organized by planner type
- **Responsive Design** - Perfect on mobile, tablet, and desktop
- **Fast Performance** - Optimized loading and navigation
- **SEO Optimized** - Meta tags and clean URLs

### Categories
- 📅 Daily Planner
- 📆 Weekly Planner
- 💰 Budget Planner
- 📚 Study Planner
- 🍽️ Meal Planner
- ✅ Habit Tracker
- 💪 Fitness Planner

### Pages
1. **Home Page**
   - Hero section with CTA
   - Category cards
   - Featured planners
   - All planners grid
   - SEO content section

2. **Planner Detail Page**
   - Large preview image
   - Download button
   - Description and tags
   - Related planners
   - Share functionality

3. **Category Pages**
   - Filtered planner listings
   - Category-specific content

4. **Additional Pages**
   - About Us
   - Contact Form
   - Privacy Policy
   - Terms of Service

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 Deployment

The site is production-ready and can be deployed to:
- **Vercel** (Recommended)
- **Netlify**
- **GitHub Pages**
- Any static hosting service

Simply run `npm run build` and deploy the `dist` folder.
